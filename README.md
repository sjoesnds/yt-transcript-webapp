# YT Transcript — веб-панель

Локальный веб-интерфейс поверх `youtube_transcript.py`: заполняешь форму в браузере,
сервер на твоей машине дёргает YouTube и возвращает транскрипт прямо на страницу.

## Установка

```bash
cd yt_transcript_webapp
python -m venv venv
source venv/bin/activate   # на Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

```bash
python app.py
```

Откроется сервер на `http://127.0.0.1:5000` — зайди туда в браузере.

## Структура

```
yt_transcript_webapp/
├── app.py              # Flask-сервер, роуты /api/video и /api/channel
├── transcript_core.py  # логика из исходного youtube_transcript.py
├── static/
│   └── index.html      # фронтенд (форма + вывод результата)
├── requirements.txt
└── README.md
```

## Если YouTube заблокирован (DPI и т.п.)

Впиши в поле «Прокси» рабочий SOCKS5/HTTP-адрес, например:
`socks5://127.0.0.1:1080`

Это то же самое, что флаг `--proxy` в исходном CLI-скрипте.

## Известные ограничения

- Режим `channel` обрабатывает видео последовательно — на больших каналах
  (сотни видео) страница будет ждать долго, прогресс-бара по каждому видео нет,
  результат приходит одним ответом в конце. Если это станет проблемой —
  можно переделать на потоковую отдачу (Server-Sent Events).
- Сервер запускается в `debug=True` для локальной разработки. Не выставляй
  его наружу (в интернет) как есть — это инструмент для личного использования
  на своей машине.
